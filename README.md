## Main features

- Custom booking form for studio sessions, add-ons, and packages
- Online payments and booking confirmations
- Multi-session package scheduling and management
- Customer rescheduling and package session changes
- Internal dashboard for sessions, packages, payments, and availability
- Custom invoice creation, editing, downloading, and emailing
- Deliverables tracking and customer email delivery
- Google Calendar integration for availability and scheduling
