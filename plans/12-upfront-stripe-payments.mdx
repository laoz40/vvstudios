# Upfront Stripe payments

Move all customer payments to Stripe upfront. No deposits, no bank transfer, no invoice emails. Receipts replace invoices. Stripe Invoicing handles post-booking charges.

## Stacked PRs (`gh stack`)

Ship each stage as its own PR, stacked on the previous one. Build one branch at a time — no need to create the full stack upfront.

**Stage 1** (from `main`):

<Code
	language="bash"
	code={`git checkout main && git pull
gh stack init upfront-stripe/1-session-checkout
# implement stage 1, commit, then:
gh stack submit`}
/>

**Next stages** (when the previous stage is done or in review):

<Code
	language="bash"
	code={`gh stack add upfront-stripe/2-package-checkout   # name from stages table
# implement stage 2 only, commit, then:
gh stack submit`}
/>

Repeat with `gh stack add` for stages 3–5. Each new branch sits on top of the current stack tip.
